# Instacode Sublime Text plugin (deprecated)
This was a plugin for easy submitting of code to [instacod.es](http://instacod.es), which was a kind of instagram for your code, but the service has since been shut down, so no need for this package anymore.

## Usage

Open Command Palette and type '__instacode__'. Press __Enter__ and the link will be opened in your default browser.

## Compatibility

Tested for compatibility in Sublime Text 3.
